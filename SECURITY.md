# Security policy

## Reporting a vulnerability

Do not report vulnerabilities, exposed credentials, or customer-data issues in a public GitHub issue.

If the repository is hosted on GitHub, use the repository's **Security** tab and select **Report a vulnerability** to open a private security advisory. If private reporting is not enabled, contact the repository owner through the organization's approved private channel.

Include:

- The affected component and version or commit
- Steps to reproduce the issue
- The impact and any known exploitation conditions
- A suggested mitigation, if available

Do not include real customer documents, credentials, or access tokens in the report. Rotate any credential that may have been disclosed.

## Supported versions

Until formal releases are introduced, security fixes are applied only to the current default branch.
