Meet the TurnB PPT Agent

Hi Team,

The TurnB PPT Agent is now available. It helps turn rough project and case-study material into a branded, presentation-ready PowerPoint deck through a guided chat experience.

Use it in your browser or directly in Microsoft Teams, and please share your feedback with the AI Team.
Access the agent
Web: Select the button below. Microsoft Teams: Go to Apps > Added by your org, then select TurnB PPT Agent.
Open TurnB PPT Agent  →

How to use it
  1. Open the agent in the browser or Teams.
  2. Upload source material or describe the case study in the chat. Word, PDF, PowerPoint, Excel, and text-based files are supported.
  3. Answer the follow-up questions and review the proposed slide content.
  4. Generate and download your branded PowerPoint deck.

This initial release is an early prototype, shared to help us validate the experience with real use cases. Your feedback will directly shape the next iteration. We would especially value your thoughts on the workflow, the quality of the generated decks, the user interface, and any features or changes that would make it more useful for your work.
